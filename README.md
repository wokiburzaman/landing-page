# Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase my web development skills, work experience, services, pricing plans, and recent projects.

## 📌 About the Project

This project is a dark-themed developer portfolio website built with modern web technologies. It presents my professional profile, technical skills, work experience, service packages, and selected projects in a clean and responsive layout.

## ✨ Features

- Modern dark-themed UI
- Fully responsive design
- Personal introduction section
- Profile image section
- Skills / advantages section with progress indicators
- Work experience timeline
- Service pricing cards
- Recent projects showcase
- Technology badges
- Clean and professional layout
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Bootstrap / Tailwind CSS
- Responsive Design
- WordPress

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY-NAME.git
```

Open the project folder:

```bash
cd REPOSITORY-NAME
```

If the project uses a package manager, install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.
